# 项目材料

[English](../en/materials.md) | [简体中文](materials.md)

随附案例的可编辑副本包含**资料节选**，不包含作者的私有原文件。节选具有新项目自己的 ID 与哈希，复制的方法引用指向这些节选。原图片来源保留为文字节选，不表示可以读取原图像素；需要重新看图理解时，请上传自己的图片。

在项目的**材料**页导入 UTF-8 `.txt`、`.md`、`.csv`、可提取文字的 `.pdf` 或静态 PNG/JPEG 截图与示例。导入、列表和预览均不调用模型。检查原始行（`L`）、PDF 页（`P`）、CSV 记录（`R`）或图片（`I1`）位置；CSV 单元格附带列号（`C`）和原始表头。日期、代码和数量不会自动解释。扫描／纯图片 PDF 会说明不支持 OCR；加密或损坏的 PDF 需重新导出。不支持复杂 PDF 版面重建。

选择位置，点击**在对话中引用选定位置**，将不可变材料 ID、SHA-256 哈希和原文附到下一次单独授权的构建对话中。解释预期含义、澄清歧义后再确认方法。规则会同时保留对话消息来源和材料引用。提示词要求助手解释理解、追问语义歧义；引用校验不能证明每项理解都正确。

选定原文随草稿修改保留，并冻结在各个确认版本中。即使文件名相同，重新导入也会创建新身份，不能改写旧版本。代码构建会收到有大小边界、明确标为不可信的 `MATERIAL-REFERENCES.json`，包含确认的原文与位置。两种构建后端均拒绝受保护确认输入的改动。生成代码不会取得原始路径或材料库访问权限。材料不能覆盖确认记录、权限、设置或系统指令。

有材料的回复通过逐条规则的结构化 `material_refs` 绑定来源，包含准确材料 ID、SHA-256 哈希及首尾均包含的 `start`／`end` 位置。范围内每个位置必须属于本次选定或此前保留的来源；不连续位置使用多个范围。可读来源说明可用中文或英文，不修改方法规则原文。缺失或矛盾的结构化归属会在更新草稿前被拒绝；确认与构建会再次检查相同映射。无材料回复保留原有结构，旧保存版本不改写。来源归属元数据另限 24,000 字节，不占用原有来源原文字节限额。

## 限制与隐私

- 每个项目最多 20 个不可变文件。文本／PDF 不超过 512,000 字节；PNG/JPEG 原件不超过 2,000,000 字节、16,000,000 个解码像素，且必须为单帧静态图。拒绝 SVG、GIF、动画、损坏、类型不匹配及带路径的文件名。即使没有 Content-Length 也限制实际请求字节；保留本机 Host、Origin 和请求头检查。
- 最多提取 100,000 字符、10,000 文本行、100 PDF 页，或 1,000 CSV 记录、50 列。预览按来源位置分页。位置或上下文过大时，请减少选择或拆分材料，不会静默截断。
- 当前方法选定及保留的来源上下文支持 128 KiB UTF-8 JSON，对话上下文上限为 2 MiB。完整数值参考和方法笔记可以一起保留；超过边界时需选择相关来源位置。当前没有向量库、自动检索或材料移除流程。
- stdlib CSV、固定 `pypdf==7.0.1` 和 `Pillow==13.0.0` 在选定的只读、无网络执行边界解析，绝不在控制器的不受限主进程解析。一次仅运行一个解析任务，但不占用全局项目修改锁；附加材料前再次检查项目状态。命令上限 20 秒、输出 800,000 字节，原生进程树内存限制为 2 GiB，Docker 工作为 256 MiB。隔离失败停止导入，不回退主机。临时范围会清理；异常清理失败会明确报告。
- 原件和解析预览保存在 `LAB_DATA_ROOT/materials/<项目 UUID>/<材料 UUID>/`；默认是本地仓库被忽略的 `materials/`。只使用生成路径，原件与解析内容均进行完整性校验。应用不为这些本机私有文件提供静态加密，请保护账户与备份。
- 材料、确认记录、构建参考和已保存文件属于本机私有项目数据，不自动公开。现有示范导出使用明确的允许清单；新增公开导出仍须单独审查内容与再分发权利。获得授权的模型请求会向配置的供应商发送选定／保留的项目上下文。

## 视觉解释与模型选择

历史执行使用 OpenAI 时，如果图片的粗略预留超过剩余授权额度，控制器可先调用官方[输入 token 计数接口](https://developers.openai.com/api/docs/guides/token-counting)。它将相同的已授权输入、图片、输出结构和工具定义交给所选供应商计数，不生成回答。细化预留使用返回的计数，另加 25% 和 1,024 个输入 token 的余量，并保留完整输出上限及原计价倍率；不会提高预算。计数失败、返回无效或细化后仍超额，均在推理前停止，不自动重试或猜测更低费用。实际请求记录计数和预留方式。其他供应商和构建助手的图片对话仍使用下述粗略规则。

私有原件保持不可变。`rgb-png-v1` 应用图片方向、将透明背景合成为白色、按比例缩至最长边 1024 像素且不裁剪，再编码为不含元数据的 RGB PNG，最大 512,000 字节。无法符合上限时拒绝并提示重新导出，不会悄悄进一步损失细节。选择前可预览真正发送的规范化图片、原始文件名、尺寸及哈希。原件和规范化文件身份均保留；预览为经过完整性检查的同源 PNG 响应，不接受调用者指定的路径或网址。

当前方法最多包含 **2 张不同的已选定／保留图片**。成功澄清后保留其身份与像素，供后续单独授权的对话使用；超量会明确拒绝。不虚构 OCR 原文、引文或识别区域。构建助手收到真实像素及标记来源，区分观察、解释、已确认规则与不确定信息，并用用户对话语言追问影响执行的模糊／不可读细节。图片内指令不能改变权限或预算。确认方法前应检查解释。

已保存连接默认是纯文本／图片能力未知。在**模型设置**中，可为闲置连接启用图片，明确确认所选模型接受图片，并按已配置的输入单价以 tokens 计费。使用已保存的密钥，启用本身不发起推理。目前仅 OpenAI Responses、Anthropic、Gemini 协议适配器支持 `token-v1` 图片计费配置；模型目录或供应商整体能力不能证明特定模型支持。其他适配器、按张收费及自定义计费不受支持。正常授权的图片请求取得有效响应后，可记录传输／结构验证成功，不保证语义理解正确。文本响应不会建立图片能力记录。设置变更和密钥更新有代次校验，不能与活跃项目／目录检查竞态。

图片请求另限 1,600,000 字节传输大小；纯文本提示、来源与代码构建上限不增加。调用前输入额度为 `文本传输字节数 + 8000 + 各图 max(32768, 编码字节数, 规范化像素数) 之和`。有限输入／输出额度按已配置单价及适用的已支持价格档位计算，其中输入额度使用已配置输入／缓存价格中的最高值，再乘以 **1.5，仅用于预留**。每图 32,768-token 下限涵盖仅按像素／字节估算会遗漏的小图、窄图基础／切片开销；不代表其他模型的图片计费公式或普遍可证明的上界。必要且受支持时，可在推理前通过有界的供应商输入计数替代粗略额度。

收到响应后，按返回的输入／输出／缓存 token 用量和保存的配置单价计价，**不乘预留系数**。工作台分别展示用量计价、待结算预留和历史预算记录。当前**没有接入供应商账单**：实扣金额是未获取，不是零，应以供应商账单为准。用量缺失／不完整、缓存价格缺失或结果未知时保留预留，不自动重试。旧记录不重新计价，也不改称账单。创建连接时可填写缓存读取／写入单价；留空不代表免费。仅对准确匹配的 OpenAI `gpt-6-luna`，未填写的缓存读取单价采用配置输入单价的标准 10% 比例；缓存写入价格须明确配置，输入超过 272,000 tokens 时按已公布的输入／缓存 2 倍、输出 1.5 倍档位计价；这些是真实价格档位，不是安全余量。其他模型按配置单价处理，不支持自定义或非 token 计费。不隐式请求快速、优先或地域溢价服务。请求证据保存价格／策略快照和图片身份，不把原始图片载荷存入项目 JSON。

已确认的代码构建输入只包含不可变图片身份和确认后的视觉解释／规则，保存在受保护文本／来源视图中，不包含 base64 像素。独立代码构建引擎**没有看过原始图片**。历史视觉执行使用另外绘制的截止时点行情图，绝不使用这些上传示例；见[执行契约](execution-contract.md)。

Windows MXC 解析已使用无害生成 PDF 和 Unicode 文本夹具验证；真实 Docker 图片解码传输夹具也已通过，覆盖大元数据 PNG、规范化身份和临时任务清理。离线夹具不能证明真实模型语义理解或跨平台验收，须另行验证。见 [Docker 验证状态](docker-local.md)。
