# 模型与预算

[English](../en/models.md) | [简体中文](models.md)

模型凭据由用户提供，只由本地后端读取。

在构建工作台的**模型设置**选择供应商，填写自己的 API Key（或明确选择使用其环境密钥），无需命名或保存连接即可**读取模型目录**。搜索并选择模型，也可手动填写**模型 ID**，再填写名称及当前单价并保存。设置接口不回传密钥，浏览器不持久保存密钥。会话模式在后端重启后失效；可选 Windows DPAPI 本机保护。读取模型目录不产生推理，也不证明全部模型能力可用。

方法对话使用下方适配器。代码构建通过原生 Codex CLI 或 Docker 后端的 OpenAI Agents SDK 连接 OpenAI Responses，尚未接入 Claude/Gemini/国内模型编码底座。Luna 只是示范选择，不是强制模型；可填写其他受支持模型及实际单价，访问权限与任务质量仍需验证。

构建使用项目共享预算、限制输入／输出；每次 Docker 构建最多 50 次请求，原生构建最多 16 次。1.5 倍安全系数仅用于调用前预留，不用于已完成用量计价。未知结果保留预算占用。生成命令不获得供应商密钥，不继承 Codex 登录，也不能联网。

示范使用 `gpt-6-luna` 和低推理配置。存在供应商适配器不代表其所有模型都支持同样的图片、结构化输出和工具能力。当前 DeepSeek 适配器会拒绝图片请求，需选择纯文本输入或合适的视觉模型；系统不会静默丢弃图片或自动切换供应商。

Qwen 可通过 `QWEN_BASE_URL` 使用支持的区域／工作区端点。自定义端点仅限允许的供应商域名。

## 模型选择与项目角色

配置顺序是**选择供应商 → 配置凭据 → 获取目录 → 搜索并选择模型 → 保存**。目录失败、不支持或未列出所需模型时，仍可手动填写 ID；这不代表允许访问任意 URL。切换供应商或凭据会清除目录，过期响应不会进入另一组凭据的界面。读取目录与付费能力测试分别处理。

每个项目独立保存用于澄清与代码构建的**构建模型**，以及可选**执行模型**。先编辑两个选项，再点击**保存模型分工**一起保存；即使两个旧连接都已失效，也可一次替换。未保存的修改会撤销费用授权，保存并重新授权后才能调用模型或构建。两者可使用相同或不同连接，纯程序方法可不选执行模型。生成项目的历史判断只使用已保存的执行角色，运行时另行授权，仍与对话、构建共用项目累计预算。杯柄示范保留独立旧配置。详见[受限执行接口](execution-contract.md)。

切换项目会恢复各自角色并清除费用授权。旧项目的两个角色明确保持未设置，需要先选择构建模型才能在页面发起真实任务。移除连接后保留可见的缺失绑定，不自动换用其他模型；请重新配置凭据或选择可用连接。项目有活动任务时不能改变角色。新增对话请求、构建请求及构建记录保存构建角色和连接快照，旧记录与费用不变；项目累计预算继续生效。

目录用于选择模型，不证明图片理解、结构化输出兼容性或编码质量。模型设置展示配置与可行动的访问错误，不展示内部验收标签。代码构建要求受支持的 OpenAI 原生或 Docker 运行环境；应检查各项目的真实文件、测试报告与运行证据，不能把一个连接当成正确性认证。

## 付费运行前

确认具体模型编号、输入能力、美元输入／输出单价及费用上限。新配置不会继承示范的付费授权。密钥放在环境变量或被忽略的本地 `.env` 中，不放进提示词或浏览器存储。

## 费用计算

一次候选机会不等于一次 API 请求。工具往返、有条件复核和修复可能产生多次请求。所有请求均计入次数与费用限制，包括已报告用量的失败调用。

发出请求前先预留预算。供应商提供时，记录输入、输出、缓存和推理用量；已经包含在输出中的推理 token 不重复计算。即使删除旧研究记录，共享授权也仍包含已发生或保守预留的费用。

项目工作台区分以下类别：

- **预算占用：**用量计价、尚未释放的预留及保留的历史预算记录之和。用于授权核算，不是实扣费用。
- **用量计价：**返回 token 数乘保存的配置单价，计入适用且受支持的缓存／长上下文档位，不乘安全系数。配置单价不等于供应商确认扣费。
- **供应商账单：**未接入。未获取账单金额不代表没有发生费用。

新请求分别保存预留、用量计价和价格快照。用量或缓存价格缺失时保留预留。旧记录保留原值，不计入新的用量金额汇总，不进行历史重新计价；原杯柄运行器单独展示的历史估计也不是账单。参见[计价详情](materials.md)。结果未知的请求保留占用，直到明确处理。达到限制时显示诊断并停止，不无限重试。

## 隐私

真实 `.env`、密钥文件、运行数据库和原始请求归档不得提交。公开示范只包含衍生结果与选定判断，不包含供应商响应编号或完整通信记录。新增导出材料在分享前仍需检查。
